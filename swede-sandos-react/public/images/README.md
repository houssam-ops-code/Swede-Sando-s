# Swede Sando's image library

The current prototype uses distinct, remote Unsplash image URLs stored in `src/data/menu.js` and the relevant components. This keeps the ZIP lightweight and avoids bundling large duplicate photographs.

When you have approved/downloaded brand photographs, place them in the folders below and replace the corresponding URLs with local paths such as `/images/sandwiches/smoky-swede.jpg`.

- `hero/` — three wide hero carousel images
- `sandwiches/` — signature sandwiches and custom sandwich
- `breakfast/` — breakfast sandwich and burrito
- `sides/` — salads and fries
- `desserts/` — cookies, brownies and baked treats
- `drinks/` — fountain drinks and beverages
- `promotions/` — combo and campaign photography

Use images you own or have permission to use. The image links currently require an internet connection.
